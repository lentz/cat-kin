# Cat & Kin

A colorful, client-side cat personality quiz built with standalone Angular. Answer six questions to get matched with one of the adoptable cats in the current cat gallery, or browse the full adoption listings. Answers are scored locally in the browser; there is no account, backend, or answer storage. Cat photos come from the shelter listings and need an internet connection.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200). The app reloads as you edit its source.

## Project structure

- `src/app/app.ts` contains the quiz questions, scoring model, adoptable-cat matching logic, and Angular component logic.
- `src/app/adoptable-cats.json` stores the adoptable-cat catalog used by the gallery and match engine.
- `scripts/scrape-adoptable-cats.mjs` refreshes the cat dataset from source listings.
- The app is intentionally static and browser-only; there is no backend, account system, or answer storage.

## Build and test

```bash
npm run build
npm test
```

The production build is written to `dist/cat-friends/browser` and can be hosted as a static site.

To run a single spec file:

```bash
npm test -- --watch=false --browsers=ChromeHeadless --include src/app/app.spec.ts
```

To run a single test by filtering the spec output, use the Angular/Karma test runner with the same file include and a browser target installed in your environment.

## Update the cat listings

The app reads its live cat directory from `src/app/adoptable-cats.json`, which is generated by the scraper at `scripts/scrape-adoptable-cats.mjs`.

To refresh the listings:

```bash
node scripts/scrape-adoptable-cats.mjs
```

This script fetches the current 24Petconnect cat listings, parses each profile page, and overwrites the JSON catalog used by the quiz and gallery. The output is written to `src/app/adoptable-cats.json` and should be committed whenever the shelter listings change.

## Customize the quiz

Edit the questions, answer trait weights, profile text, and cat-photo details in `src/app/app.ts`. The matcher compares answer trait weights to each adoptable cat's profile and filters out unsuitable home-type matches; quiz navigation and answers use Angular signals.
